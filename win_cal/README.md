# win_cal

바탕화면 아이콘 뒤에 붙어서 항상 보이는 Windows 일정·업무 관리 위젯

**최신 버전 v11.6.6** (2026-09-13) · Windows x64 · 오프라인 동작

## 주요 기능

**바탕화면 위젯**
- 일반 창처럼 떠 있지 않고 바탕화면 아이콘 뒤 층(WorkerW)에 고정되어, 다른 창을 가리지 않고 배경처럼 항상 보입니다.
- 편집 모드에서만 위치·크기를 바꿀 수 있어 평소에는 실수로 움직이지 않습니다.
- 절전 해제·해상도 변경·DPI 변경 뒤 위젯이 풀리거나 크기가 틀어지면 스스로 다시 고정합니다.
- 배경 색·이미지, 투명도(배경에만 적용 가능), 테두리·격자선·요일 색, 오늘 날짜 강조를 설정할 수 있습니다.

**일정**
- 여러 날에 걸친 일정, 시작·종료 시간, 서식 있는 본문(굵게·밑줄·글자색·형광펜)
- 주·월·년 반복, 반복 일정 수정·삭제 시 "이번 일정만 / 이후 모두" 선택
- D-day 표시(임박하면 색 변경, 지난 일정은 "-N일"), 한국 공휴일 표시(임시공휴일 수동 새로고침)
- 색상 프리셋: 그룹별 관리, 프리셋 색을 바꾸면 그 프리셋을 쓰는 일정에 한 번에 반영

**반복 업무**
- 요일별 할 일 체크리스트, 날짜별 완료 기록
- 제목의 `$` 자리에 회차 번호 자동 부여 (예: "`$`주차 과제" → "1주차 과제", "2주차 과제" …), 지정한 번호의 주는 건너뛰기

**프로젝트**
- 상·하위 항목 트리, 하위 항목 완료율로 상위 진행률 자동 계산, 전체 흐름도 보기

**시간표**
- 주간 교시 표, 과목별 여러 수업 시간, 강의실·교수·온라인 강의 구분
- 과목별 일정·과제·시험을 등록해 메인 달력과 연동, 시간표 기간 진행 막대

**엑셀 보고서**
- 일간·주간·월간·연간 일정을 .xlsx로 출력 (일정 색상 반영, 반복 일정 포함 선택)

**기타**
- 한국어·영어 전환, Windows 시작 시 자동 실행, 트레이 아이콘

## 설치

1. `win_cal-11.6.6-setup.exe`를 실행합니다.
2. 설치가 끝나면 바탕화면 바로가기가 만들어지고, 위젯이 바탕화면에 나타납니다.
3. 이전 버전이 설치되어 있으면, 제거하고 새로 설치할지 먼저 묻습니다.

- 처음 실행하면 14일 체험판으로 시작합니다. 이후에는 활성화 코드가 필요하며, 코드는 인터넷 연결 없이 Ed25519 전자서명으로 검증합니다.
- 공휴일 정보를 받아올 때만 인터넷을 사용합니다. 나머지 기능은 모두 오프라인에서 동작합니다.

## 사용 방법

1. **편집 모드**를 켜고, 위젯을 길게 눌러 크기와 위치를 맞춘 뒤 편집 모드를 끕니다.
2. 날짜 칸을 눌러 일정을 추가합니다. 자주 쓰는 색은 색상 프리셋으로 저장해 두면 한 번에 적용할 수 있습니다.
3. 사이드 패널의 **반복 일정** 탭에서 요일별 할 일을 등록합니다. 제목에 `$`를 넣으면 회차 번호가 자동으로 붙습니다.
4. **설정 → 내보내기/백업**에서 기간을 골라 엑셀 보고서를 저장합니다.

## 기술 구성

| 분류 | 기술 |
|---|---|
| 실행 환경 | Electron 39 |
| 화면 | React 19, TypeScript, Tailwind CSS 4, lucide-react |
| 상태 관리 | Zustand 5 |
| 데이터 | SQLite (better-sqlite3), electron-store |
| 본문 편집 | Tiptap 3 |
| 엑셀 출력 | ExcelJS |
| 다국어 | i18next |
| Windows 연동 | Win32 API (상주 PowerShell + C#) — 바탕화면 고정, 포커스 제어 |
| 공휴일 | Nager.Date API (연도별 캐시) |
| 라이선스 | Ed25519 전자서명 (오프라인 검증) |
| 배포 | electron-builder (NSIS 설치 파일) |

```
src/
├── main/                  # 메인 프로세스
│   ├── desktopEmbed.ts    # 바탕화면(WorkerW) 고정 · 자가복구
│   ├── eventsDb.ts        # 일정 DB
│   ├── recurringTasksDb.ts / progressItemsDb.ts / timetableDb.ts
│   ├── exportEvents.ts    # 엑셀 보고서 출력
│   ├── backup.ts / dataLocationMigration.ts
│   ├── holidays.ts        # 공휴일 API + 연도별 캐시
│   └── license/           # 체험판 · 활성화 코드 검증
├── preload/               # 화면 ↔ 메인 IPC 브리지
├── renderer/src/
│   ├── features/          # calendar, events, progressItems, recurringTasks, timetable, settings
│   └── shared/            # i18n, 공통 UI, 스토어
└── shared/                # 공통 타입 · 입력값 검증
```

> 소스 코드는 비공개로 관리합니다.
