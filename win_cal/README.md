# win_cal

바탕화면에 고정되는 Windows 일정·업무 관리 위젯

| 항목 | 내용 |
|---|---|
| 개발 기간 | 2026.07.07 ~ 2026.09.13 (약 10주) · NVIDIA DLI 수료 전 |
| 역할 | 1인 기획 · 디자인 · 개발 · 배포 |
| 개발 규모 | 개발 커밋 77건 (문제 수정 23건 포함), v1.0 → v11.6.6 |
| 주요 기술 | Electron, React, TypeScript, SQLite, ExcelJS |

## 개발 배경

- 기존 일정표 프로그램 중 원하는 형태가 없어 직접 개발
- 바탕화면에서 바로 일정을 확인·추가·삭제할 수 있는 형태 필요
- "3주차 과제"처럼 회차가 붙는 반복 업무를 표현할 방법이 없음

## 주요 기능

| 기능 | 내용 |
|---|---|
| 바탕화면 위젯 | 바탕화면 아이콘 뒤에 고정, 투명도 · 배경 이미지 설정 |
| 일정 관리 | 기간 일정, 반복 주기(주·월·년), 서식 있는 본문, 색상 프리셋 |
| 반복 업무 | 요일별 할 일, "$주차" 자리에 회차 번호 자동 부여, 휴무 주 건너뛰기 |
| 프로젝트 | 상·하위 항목 트리, 하위 완료율로 전체 진행률 자동 계산 |
| 시간표 | 과목·수업 시간 관리, 과제·시험 일정과 연동 |
| 일정 엑셀 출력 | 일·주·월·연 단위 .xlsx 자동 출력 (일정 색상 반영) |
| 데이터 보존 | 다른 드라이브로 저장 위치 이전, 백업 · 복원, 한/영 전환 |

## 문제 해결 사례

| 문제 상황 | 원인 | 해결 | 결과 |
|---|---|---|---|
| 편집 창을 열 때마다 위젯이 깜빡이고 느려짐 | 창을 제어할 때마다 보조 프로그램을 새로 실행 | 보조 프로그램을 한 번만 실행해 계속 재사용 | 매번 0.1초 이상 걸리던 준비를 최초 1회로 |
| 해상도가 바뀐 뒤 위젯이 작아진 채 고정 | 해상도가 바뀌는 순간의 창 크기가 저장됨 | 편집할 때만 크기를 저장하도록 변경 | 해상도 변경 후에도 크기 유지 |
| 복구 기능 때문에 바탕화면 전체가 깨짐 | 창을 다시 띄우는 동작이 복구 기능을 또 실행 | 창을 조용히 띄우고 2초 간격 제한 추가 | 반복 실행 차단 |
| Windows 종료·재시작이 지연됨 | 창을 닫아도 숨기기만 해 종료 신호에 무반응 | 종료 신호를 받으면 즉시 종료 | 정상 종료 |
