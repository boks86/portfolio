# Learn_TEXT

음성 추출 → 텍스트 추출 → 요약 → 암기카드까지 하나로 이어지는 Windows 데스크톱 AI 파이프라인 (강의 녹음에 적용, 개인 학습용)

| 항목 | 내용 |
|---|---|
| 개발 기간 | 2026.09 ~ 현재 · NVIDIA DLI 수료 후 |
| 역할 | 1인 기획 · 디자인 · 모델 선정 · 개발 · 배포 |
| 개발 규모 | 설치 파일 약 2주간 38회 배포 (09.14 ~ 09.29), 최신 v15.7.4 |
| 주요 기술 | Python, faster-whisper, Electron, React, SQLite, LLM |
| 개발 환경 | 외장 GPU 없는 Windows 노트북 (CPU로 음성인식) |

## 개발 배경

- DLI 수료 후 배운 AI 모델을 실제 데이터 처리에 적용
- 음성 추출 → 텍스트 추출이 하나로 이어지는 자동 파이프라인을 목표로 설정
- 적용 대상은 매주 생기는 90분 분량의 강의 녹음 (전문용어가 많아 인식 품질 검증에 적합)

## 파이프라인

**음성 추출 → 텍스트 추출 → 정리·검색 → 요약 → 암기카드**

| 단계 | 처리 내용 |
|---|---|
| 음성 추출 | PC에서 나오는 소리를 별도 장치·드라이버 없이 직접 녹음, 음성인식용 형식으로 저장 |
| 텍스트 추출 | 녹음이 끝나면 자동으로 대기열에 등록 → faster-whisper로 텍스트·자막 파일 생성 |
| 정리·검색 | 과목·강의별로 목록 DB(SQLite)에 저장, 요약 내용까지 검색 가능 |
| 요약·암기카드 | 시험대비·개념정리·핵심요약 3종 요약, 요약으로 Anki 암기카드 파일 생성 |
| 자동 설치 | 첫 실행 시 Python·음성인식 모델 등 필요한 환경 자동 설치 |

## 음성인식 모델 선정

| 모델 (faster-whisper) | 정확도 | 속도 | 비고 |
|---|---|---|---|
| **large-v3** | 가장 높음 | 느림 | 기본값 |
| large-v3-turbo | 다소 낮음 | 빠름 | 설정에서 전환 |
| medium | 낮음 | 가장 빠름 | 설정에서 전환 |

텍스트가 요약·암기카드의 원료이므로, 작은 모델 대신 가장 정확한 모델을 유지하면서 가볍게 돌리는 방향을 선택했습니다.

## GPU 없는 환경 최적화

| 구분 | 방법 | 효과 |
|---|---|---|
| 모델 경량화 | 계산 정밀도를 낮춘 경량 모드(int8) | 정확도 유지, 메모리·연산 감소 |
| 코어 배분 | CPU 코어 2개는 남겨두고 변환 | 변환 중에도 PC 사용 가능 |
| 녹음 형식 | 처음부터 음성인식용 형식(16kHz 모노)으로 녹음 | 데이터량 약 1/5.5 |
| 무음 구간 | 소리 없는 구간은 건너뜀 | 불필요한 계산 감소 |
| 메모리 | 녹음 데이터를 즉시 압축 형식으로 변환 | 2시간 기준 460MB → 230MB (계산값) |
| 보관 용량 | 변환 후 mp3로 압축 | 90분 기준 173MB → 43MB (계산값) |

## 문제 해결 사례

| 문제 상황 | 원인 | 해결 | 결과 |
|---|---|---|---|
| 같은 문장이 수십 번 반복되고 변환이 멈춘 듯 느려짐 | 소리 없는 구간에서 AI가 앞 문장을 계속 따라 만들어 냄 | 앞 문장 참조를 끄고, 3번 이상 반복되는 구절은 1번으로 줄임 | 반복 문장과 장시간 정체 해소 |
| 한글 이름 파일이 변환되지 않음 | 음성 처리 라이브러리가 한글 경로를 열지 못함 | 영문 이름의 임시 파일로 복사해 처리 | 한글 파일 정상 변환 |
| 강의 1개 요약에 여러 번 나눠 붙여넣어야 함 | 나누는 기준이 너무 작았고(15,000자), 분할도 제대로 안 됨 | 기준을 45,000자로 올리고 줄 단위로 나누도록 수정 | 붙여넣기 4회 → 1회 (40,000자 기준) |
| 목록을 다시 만들면 완료 표시가 사라짐 | 다시 만들 때 녹음 길이 정보가 비어 버림 | 실제 파일에서 길이를 다시 측정해 채움 | 완료 상태 유지 |

## 요약 엔진

- 기본: Claude 반자동 요약 (프롬프트 복사 → Claude에 붙여넣기 → 결과 저장)
